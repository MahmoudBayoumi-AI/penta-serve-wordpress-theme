# ❄️ PENTA SERVE KSA — Custom WordPress Theme

**Tech Stack:** `WordPress` · `PHP` · `CSS3` · `Vanilla JavaScript` · `Bilingual (AR/EN)` · `RTL/LTR`


A custom, lightweight, and fully responsive WordPress theme built from scratch for **PENTA SERVE KSA** — a specialized company in developing commercial refrigeration and freezing warehouse solutions in the Kingdom of Saudi Arabia.

🌐 **Live Website:** [https://pentaserveksa.com](https://pentaserveksa.com)

---

## ✨ Key Features

* **Bilingual Support (AR / EN):** Built-in multi-language architecture (`inc/content/ar.php` & `inc/content/en.php`) with full RTL and LTR layout adaptation.
* **Custom Theme Customizer:** Dynamic control over site sections, colors, and content directly from the WordPress Customizer (`inc/customizer.php`).
* **One-Click Setup / Installer:** Automated initial page and content setup script (`inc/installer.php`) for rapid deployment.
* **Built-in SEO Optimization:** Custom meta tags, structured data, and clean semantic markup (`inc/seo.php`).
* **Custom Shortcodes & Blocks:** Modular UI components and shortcodes (`inc/blocks.php` & `inc/shortcodes.php`) tailored for industrial services and investment solutions.
* **Custom Contact Handler:** Dedicated form processing and validation (`inc/contact.php`) integrated with business communication channels.
* **Performance-Focused:** Zero reliance on heavy page builders, utilizing clean Vanilla JS (`assets/js/main.js`) and optimized WebP assets.

## 📂 Theme Architecture

```text
penta-serve-v26/
├── assets/
│   └── js/
│       └── main.js        # Interactive UI, navigation, and animations
├── inc/
│   ├── content/
│   │   ├── ar.php         # Arabic localized content strings
│   │   └── en.php         # English localized content strings
│   ├── blocks.php         # Custom content blocks
│   ├── contact.php        # Contact form submission & handling
│   ├── customizer.php     # WordPress Theme Customizer settings
│   ├── helpers.php        # Reusable helper functions
│   ├── installer.php      # Automated theme & page setup
│   ├── seo.php            # Custom SEO meta & schema logic
│   └── shortcodes.php     # Custom theme shortcodes
├── 404.php                # Custom 404 error template
├── footer.php             # Global footer template
├── functions.php          # Theme setup, enqueues, and core hooks
├── header.php             # Global header & navigation template
├── index.php              # Main fallback template
├── page.php               # Default page template
└── style.css              # Main theme stylesheet & WordPress header
```

## 🚀 Installation

1. Download or clone this repository.
2. Compress the theme files into a `.zip` archive (e.g., `penta-serve.zip`).
3. In your WordPress Admin Dashboard, navigate to **Appearance > Themes > Add New > Upload Theme**.
4. Upload the `.zip` file, click **Install Now**, and then **Activate**.
